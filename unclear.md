# Unclear

Trip-ups and unclear points met while working on ulang code, each with what was wrong and what is so, until the
documentation is fixed from them (see the working rules of `CLAUDE.md`), when they move into the items of `ideas/`.

- A procedure lambda without formals, `lambda in => p(…) end`, and the type `() raises OsError` of a procedure without formals were guesses that do not parse: CLAUDE.md, Semantics, gives the forms of procedure values only with formals, and says nothing of one without.
- **`catch case ParseError(message, _)` around `parse_file_text` is `UndeclaredRaise`**, since `ParseError` has other constructors, `ImportError` and `ParseErrors`, which the handler leaves raised; `case e => … parse_diagnostic(e).message` covers them all, as `parsed` of `ulang/refactor/refactor.u` does.
- **A module whose sections are all emptied becomes a file without sections**: `format` writes no empty section, so dropping every export of a module leaves only its declarations, without `export` and `implementation`, which then all count as implemented.
- **`Var.name` is a `Name`, `Id` is `Str`**: a set of the names that an expression reads, `expr_names` of `ulang/lint/lint.u`, is of `Id`, the bases, so a `Var` compares by `x.name.base`; the error was a mismatch of `Set[Str]` and `Set[Name]`.
- **A multi-assignment built as a tree in a test also depends on its meaning**: the lint that found the assignments that read each other walks parsed sources only, and missed the `sum` of the test `procedures` of `ulang/run/run.u`, whose `SAssign` is built by hand and which then computed 14 instead of 10.
- **`check` judges by the built checker, not by the sources**: after an experiment that changed `ulang/check/check.u` and ran `make`, reverting the source left `out/ulang.bin` with the experiment, which kept reporting its errors; and sources halfway through a change of types cannot be built, so a change of the checker's own datatypes is checked by the binary of the commit before, built in a worktree of its own.
- **`var a, b, c, d: Int` types only `d`**: the type of a declaration of `var` belongs to its own name, so `b` and `c` were `missing type for b`, while `a` took its type as the out of the call right after the declaration; each takes its own, `var a: Int, b: Int, c: Int, d: Int`.
- **A test file for `@fix` without an entry or exports loses its declarations**: `UnusedPrivate` fires on every function and its fix drops them, which hides the edits under test.
- **`normal_file(here, here, root)` with the root as the working directory gives the absolute root**, not `.`, so it compares with no relative path.
- **There is no negation of expressions**, only negative literals, so `-x` is written `0 - x`; CLAUDE.md says only that `-n` of a number is a literal.
- **`format` does not rewrap comments longer than 120 characters**, which then stay as written.
- **`is_numbered` of `ulang/lint/lint.u` flags only one digit after a letter**, so `sha256` and `x86` were never warned on, while `utf8` and `pop3` were.
- **An interpreted run of one case of `ulang/test/errors/` loads its whole file**, 1.5 to 3.5 minutes per case on a loaded machine, not the cheap run that CLAUDE.md suggests.
- **A regression test of an order passed without the fix**: `measure_slots` of `ulang/prove/termination.u` only fails when the function without formals comes first in the component, which the names order, so the case names it `base` before `count`; a case of a bug that depends on an order is checked against the code before the fix.
- **The compilers call a function directly only if the type of its name has the arity of the call** (`arity(ty) == size(args)` in `compile_named` of `ulang/compile/compile.u`), so code that an expansion makes after checking needs a function type of the right arity on its names, `TFun` of holes in `form_call` of `ulang/expand/expand.u`, and `THole` makes every such call `u_apply`.
- **The anchor of `@put after` is a declaration written `file.u:name`, not a bare name**, which the refusal of a bare name now writes as the form to take.
- **A new builtin that compiled code calls needs the seed first**, also one called only by the interpreter and the library: the seed's `native_procs` of `ulang/compile/lower.u` does not know it, so the C of `make` calls a mangled name that nothing defines; the builtin goes in with the runtime and `lower.u` first, then `make selfcompile`, then its uses.
- **The verdict and the check of a refactor script are in `run_actions` of `ulang/refactor/refactor.u`, not `run_script`**, which only reads the script and passes it on, so a `@patch ulang/refactor/refactor.u:run_script` of their lines was refused as not occurring, with the whole line quoted as the old text.
- **The constructions of `ulang/compile/compile.u` and `ulang/compile/x86.u` are in `compile_named`, not `compile_expr`**, which has only the tuples, so a `@patch` of `compile_expr` at the `u_mk_con` call was refused; and Compiler 12 said that the list of the runtime functions that `ulang/compile/x86.u` calls gets the new names, while its only such list is `variadics`, of the functions that take variable arguments, which the functions of fixed arity must not join, since `call_runtime` sets `%al` only for them, and every other runtime function is called by `@PLT` by its name alone.
- **`linted` of `ulang/test/lint/lint.u` parses without the notation of the library**, so a text of a lint test with `!=` or `+` fails with `undeclared operator`; such texts call functions instead, `plus(n, y)`.
- **`builtin` is a keyword**, so no field, formal, or local takes it, as `export` and `implementation` do not; the field of the builtin lines of `Parts` of `ulang/refactor/refactor.u` is `builtins`, as that of `Mod` is. And `option` has `exists` and `forall` but no `find`, so a filter of an `Option` is a comprehension over it, `List(for k in o if p(k) yield k)`.
- **The reply of `run_script` keeps a refusal of several lines as one element**, `List("rejected", "…\n…")`, so a test that expects the lines of a long refusal compares one string with newlines, not a list of lines (`patches_after_drops` of `ulang/refactor/test/declarations.u`).
- **A `let` with the declared type of a procedure value does not type the formals of its lambda**: `let passed: (in List[Str], List[(Str, Diagnostic)], out Tests) := lambda in paths, _, out tests => … List(for p in paths …) …` is an `UnknownContainer` at `paths`, while CLAUDE.md says that the declared type of a local gives a lambda its expected type; the ascription `(paths: List[Str])` in the generator checks.
- **Updates chain from the left, also after `let … in`**: `node with span := span with start := p` updates `start` of the `Node`, not of the `Span`, `UnknownField: unknown field start of Node`, and `format` wrote the `let` before it in parentheses, `(let span := node.span in node with span := span) with start := …`; an update of a field's field is `node with span := (span with start := p)`, or a construction, `Span(p, node.span.stop)`. And `if c then node with span := s else node` is a parse error, `else expected but with found`, so an update in a branch of an `if` expression takes parentheses.
- **`prefix` is a keyword**, of the notations `prefix`, `infix`, and `postfix`, so a local `prefix` is `keyword prefix is not a name`, which the hint of other keywords does not name a replacement for.
- **A `@patch` of one declaration formats the whole file**, so an unformatted layout of another declaration of a test's sample, such as a call broken over two lines, is joined by the first patch that succeeds; a case that needs the broken layout runs before it (`patches_parts_of_lines` of `ulang/refactor/test/declarations.u`).
- **The margin of `@show` has a fixed width**, six columns, so a handle that gains a digit, `#9` to `#10`, takes one space from the margin, which test expectations that shift handles must narrow too.
- **The tests of `ulang/refactor/test/` keep the journal of their directory between runs**: a test that writes only an empty `handles.txt` and expects `script 1 of the journal` passes once, then sees `script 2`, so an expectation leaves out the line of the journal.
- **Handles in the replies of tests count the heads of signatures**: since Refactor 56, `@show` of an exported declaration numbers the head of its signature first, so `#1` of a test that names the head of the definition is `#2`.
- **A local may not be named `checks`** in a file below the root, since `checks/` is a package of the project, `QualifierLocal: checks is the first name of a path that the module sees`, also in `checks/` itself.
- **The width of `format` is 80 columns for code, but comments are filled to 120**, a convention that `ulang/format/format.u` does not state and nothing checks, so the warning of Refactor 60 on long comment lines takes 120 from the comments of the sources, where most lines of comments are 100 to 120 wide.
- **A comprehension takes no `let` between its generators**: `List(for (n, t) in cs let fs := f(t) for x in fs yield …)` is `) expected but let found`, so the value is computed in each generator that needs it or by a helper.
- **Two members of a package may declare tests of the same name**, which `check` accepts, since tests are private to their file, and the runner of the package runs both under the one name, against the rule of CLAUDE.md that names are distinct.
- **`prefix` and `suffix` are keywords**, of notations (`keywords` of `ulang/parse/lex.u`), so neither names a field or a local, as `before` and `after` can; the fields of `BlockMatch` of `ulang/refactor/refactor.u` are `lead` and `trail`.
- **The lints walk the claims of lemmas**, `exprs_lints` of `claim_exprs` in `placed_cmd_lints` of `ulang/lint/lint.u`, so `BoolIte` reports `ensures b == false` and `ensures (if c then x else x) == x` of the tests of the prover, where the equation is the statement itself, and not a body to simplify.
- **The tests of `ulang/refactor/test/` see only the exports of `ulang/refactor`**: a test that called `get_at` of `ulang/refactor/refactor.u`, a private helper, was `UnknownVariable: unknown variable get_at`; such a test takes the functions of the library, `join("\n", reply)` and `starts_with`.
- **`CLAUDE.md` named `infer_against` of `ulang/check/check.u`**, which `infer_expected` replaced in 63ae6e7, so `make testdocs` failed on `main` until the name was fixed; a rename of a declaration that a doc names fails only the compiled `make testdocs`, not `make test`.
- **`F:coverage` of `refactor` was refused without a reason**: `ulang/check/check.u` has a procedure `coverage` and a test `coverage`, so the target takes the arity, `coverage/4` (Refactor 66).
- **`pkill -f` of a pattern that the command line of the shell contains kills that shell**: `pkill -f "worktrees/…/out/ulang.bin" ; make …` in one background command ended it with status 144 before `make` ran; stop the tasks by their ids instead.
