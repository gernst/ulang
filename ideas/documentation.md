# Documentation

1. **Comments may show syntax that the language does not have**: the prelude described lists as `[a, b; xs]`, sets as `{a, b}`, and arrays as `|a, b|` long after the forms replaced them, which an agent reads as ulang (the design review of 5cd2fe1). Solution: a check of `checks/docs.u` that the comments of the sources contain no syntax that the lexer rejects, such as `[a, b]` outside type arguments.
2. **Texts that agents misread** (Refactor 5T and 5B, 16 November 2026): `LANGUAGE.md` says that building an array copies it, which ubox took as the cost of `Array(for … yield …)` and replaced by `from_list` for nothing (5B6); the doc of `os_remove_all` of `ulang/prelude/os.u` does not say that a missing path raises `OsError` (5T9); the README says that `refactor` takes one action on the command line, which the mail client read as one kind that repeats (Refactor 31); the rule that examples follow the `:=` of a signature in `export` or of a private definition did not tell it that the definition of an exported function has none (5T5); and ubox wrote `grep` without regular expressions since "there is no such library", although `library/regex` is one, which nothing that an agent reads names. Solution: `LANGUAGE.md` says that each change of an array copies it, not its construction, and lists the packages of `library/` with what each offers; the doc of `os_remove_all` names the missing path; the README gives the form of the command line; and the rule of examples names `ExampleOnDefinition`.
