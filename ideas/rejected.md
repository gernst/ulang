# Rejected and decided

- **A faster `ulang/run/run.u`** by numbering the names of declarations and variables when a program is loaded, so that the environments compare integers, and **integers tagged in the pointer** in the runtime, to save the boxes of most integers: both rejected.
- **Hash consing** of all constructors and tuples in the runtime, tried and removed (`be1808d` is the state without it): 70% of the constructions of the compiler and 85% of `run.u` equal a live value, and peak memory fell by 40–57%, but it was 2.2–2.5 times slower from cache misses, a bucket, its entry, and the candidate for every construction. **Maps and sets ordered by hash** were 18% slower for the compiler and 75% for `run.u`, since hashes outside -16..255 are boxed and `Name` keys differ early anyway. Consing particular structures, such as types or the terms of `prove/`, for memory or identity is still open.
- **A stack machine** for the interpreter, whose stack and code would be lists or maps, and **mutable arrays**, which values shared by two variables, atomic effects, and the restoring of variables by `try` exclude: rejected.
- **Partial field accesses** marked at the access, as `e!f`, or rejected statically: dropped, `MissingField` stays.
- **View patterns** `f -> p` beside the pattern aliases: rejected, since they call a function, which defeats the exhaustiveness check and need not terminate; pattern aliases are expanded instead. **Aliases of qualified names**, `Qualified(module, base)` for `Name(Some(module), base)`: not worth it.
- **Refutable patterns in generators**, such as `for Some(x) in xs`: rejected, both skipping the elements that do not match, as in Haskell, which hides a filter in the pattern and silently drops elements whose shape a mistake changed, and failing at run time, which makes a generator partial. Generators bind only irrefutable patterns (the forms), and a filter is a guard, `for o in xs if o != None`, or a `match` in the element.
- **A form `fold(let n := 0; for x in xs if p(x) yield n + 1)`** of a loop that accumulates: not unless code shows a need, since `foldl` and a `for` statement already write it, and agents do best with one way of each.
- **`call` and `assign`** were dropped, and **`local`** split into `let` and `var`: a statement that starts with a name is a call if `(` follows and an assignment if `:=` follows, so the grammar needs two tokens there, and the declarations, which stand anywhere in a body, show where a name gets its value and whether it changes. **`skip`** stays, **`in`** stays at calls, **`test name()`** keeps its parentheses, and **`[…]`** stays for type arguments, while containers are written by the forms `List(…)`, `Set(…)`, `Map(…)`, and `Array(…)`; delimiters, `[…]` for lists, `{…}` for sets and maps, and `|…|` for arrays, were set aside, since the empty set and the empty map need two texts that `show` can print, `{}` and `{=>}`, and `|…|` does not nest, `||1|, |2||`; a `[…]` for lists alone stays possible on top of the forms.
- **Guards that bind**, such as `if let`, for code that tests `!= None` and then matches again: rejected; such code is one `match` over a function that classifies the case once, as `fusion_of` of `ulang/compile/lower.u` does for the calls that compile to loops.
- **User-defined notations** stay, although parsing depends on the imports.
- **`++` of arrays** is deferred, since arrays are built by forms.
- For the forms: no **`break`**, since a `for` runs to the end and an early exit goes through `while` or an exception; no **`Seq` type** or comprehensions without a form, since the form says what is built; no **choice of the result by the expected type**, the problem of Scala's `CanBuildFrom`, which violates locality; and no **`let` between generators** until code needs it.
- **Chains of conditions**, by `elif` or by a `when` with arms `if c => …`, tried and removed: `if` always nests, and an `if` after `else` is an `if` in its body, with its own `end`.
- **`Char`** stays a type of its own.
- **Functions may raise**, where `requires` states their domain (Verification 1).
- **Subpackages private to their parent, with re-exports** from the parent, as in Rust (`pub use`): rejected, since importing a subpackage from elsewhere is sometimes useful, and a re-export is a second way to reach the same declarations, the one transitive import, after which an import line no longer names the package that its names come from.
- **Imports relative to the importing file**, as in JavaScript, Zig, and the `#include "…"` of C: rejected for imports from the root, although they read each file in isolation and keep the imports of a subtree that moves, since a package then has a spelling per place, its importers are found only by a pattern, chains of `../` grow with nesting, and dependencies need a second form anyway, so that projects in JavaScript add path aliases and Python recommends absolute imports.
- **Overloading by type within a module**: tried and removed. Within a module, functions overload only by their number of arguments, and by type only across modules, which qualify their names, also across the files of a package. Telling apart the declarations of one name and arity in one module took an encoding of their types into their names, `f{(T) -> R}`, undone wherever names were compared, since a function is known by its module, name, and arity in `Sig`, `Defs`, and both backends; two hooks of one name, such as the shows of two datatypes, go into two modules.
- **A drastically faster interpreter**: rejected; it is about 300 times slower than compiled code, e.g. 11 seconds against 35 milliseconds for a case that loads the library, and minutes against 2 seconds for parsing the sources of the compiler, so such tests run only compiled, `ulang/test/errors/` by `project.u` and the checks of `checks/` by their `main`. The quick loop of an agent on large inputs is compiled tests, `test --compiled` of Build 1, not the interpreter.
- **The runner of the binary of the tests in ulang**, as a private procedure of `ulang/prelude/os.u` over procedure values of the tests, which `main` would build: rejected; it would still be a second copy of the selection of `ulang/ulang.u`, which the library cannot import, and couple `ulang/compile/compile.u` to a private name of the library, so the selection stays in C, `u_run_tests` of `ulang/runtime/ulang.c`.
- **A lint for handlers that read a variable that the body of their `try` assigns**, which they see as before the `try`: rejected for its false positives, measured as 17 warnings at 15 handlers of the project, none a mistake, since the rollback is the idiom of the backtracking parser (`toks`), of the checker, which adds the error to the state from before the failed command (`s`), and of the interpreter's own `try` (`env`).
