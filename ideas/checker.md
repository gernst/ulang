# Checker

1. **A raise cannot become a value**, so code that collects an error catches each kind into an out, as `check_file` of `ulang/ulang.u` does with the message of each phase, and the long `raises` of the helpers of `ulang/test/cases/cases.u` list every phase. Solution: a statement that gives an `Option` of the exception of a call, or a `try` with a result, and the exceptions of the phases as one datatype of `ulang/syntax/error.u`.
2. **Termination is a style rule only**, so the split between functions and procedures guarantees nothing, and unfolding a function that does not terminate can prove false. Solution: the prover proves the termination of the recursive functions that the lemmas of a module reach, by structural recursion or a lexicographic order of measures from the guards, each call an obligation of the simplifier, and uses the definitions of only those as rewrite rules, while `prove` and `test` report a termination error at a call that does not decrease; the checker stays out of it, `decreases` after `:=` is the fallback measure, and a check of the repository lists the functions of `ulang/` whose termination is not proven (`ideas/prove.md`, section 6).
3. **Unused imports are accepted silently**, so which packages a member needs is found only by removing each import in turn and checking, as when `ulang/` was split into packages, and a scan of exported names over the sources overstates the dependencies by words in docs and names that several modules declare. Solution: the checker rejects an import of a package of which the module uses nothing, at the position of the import, as `UnusedImport`.
4. **No polymorphism over exceptions**: a procedure type carries its raises as a fixed set (`raised` of `TProc`), so a generic `apply`, `each`, or `retry` must fix in its type what its argument may raise, and a lambda bound by a `local` without a type, or returned by a function whose result type omits the raises, is `UntypedRaise`. Solution: a parameter of the raised set in procedure types, `(in A) raises E`, instantiated per use, designed together with `uses os` (Later 1) as one set of effects.
5. **An entry may let a checked exception escape**: `main`, private, raises what its body infers, so `run` ends with `uncaught exception A` that the checker could have reported. Solution: decide whether the entries of `run` and `compile` and the tests raise nothing, an error at the raise or call as `UndeclaredRaise` is, or declare their raises.
